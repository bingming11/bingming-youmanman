# 邮满满云仓 · 报价查询中心（本地报价展示网站）

把「邮满满云仓报价表」文件夹里的 Excel / CSV 报价表，自动解析成可搜索、可筛选、可排序的
本地网页。新增或替换报价文件后，重新跑一次解析脚本即可同步内容，**无需修改任何代码**。

样式参考云途（YunExpress）报价页：青绿 + 琥珀配色，顶部数据概览，分类标签页 + 工作表胶囊，
关键词搜索 + 条件筛选 + 表头排序，金额与单位统一格式化（¥ 前缀、等宽数字）。

---

## 一、目录结构

```
邮满满云仓报价表/                 ← 【数据源】放报价表文件（.xls / .xlsx / .csv）
  └─ 邮满满云仓+云途特惠+欧美专线0810(3).xls
quote-site/                      ← 【本网站】，可整体复制到其他电脑直接运行
  ├─ index.html                  ← 网页入口（双击即可在浏览器打开查看）
  ├─ parse_prices.py             ← 核心：扫描数据源 → 解析 → 生成 data.js
  ├─ server.py                   ← 本地服务器 + 一键刷新接口（POST /refresh）
  ├─ run.bat                     ← 一键：建环境 → 解析 → 起服务 → 开浏览器
  ├─ refresh.bat                 ← 一键：仅重新解析并刷新（服务已在运行时用）
  ├─ requirements.txt            ← Python 依赖（xlrd==1.2.0, openpyxl）
  ├─ assets/
  │   ├─ style.css               ← 页面样式（青绿+琥珀主题，含运费试算弹窗）
  │   ├─ app.js                  ← 前端渲染与交互（搜索/筛选/排序）
  │   └─ calc.js                 ← 运费试算器（读取报价表实时估算）
  └─ data/
      ├─ data.js                 ← 解析结果（window.YUNMANMAN_DATA，前端直接引入）
      ├─ status.js               ← 解析状态（版本号/更新时间/是否成功/报错）
      └─ data.prev.js            ← 上一版备份（解析失败时回退用）
```

> 数据以 `<script>` 全局变量方式注入（`data/data.js` + `data/status.js`），因此
> **双击 `index.html` 即可直接查看**（file:// 模式，无需服务器）。但“重新解析报价”
> 仍需运行 Python 脚本（见下文「如何更新」）。

## 二、默认假设（如与你的实际不符，按对应说明调整即可）

| 项目 | 默认值 | 说明 |
|------|--------|------|
| 数据源目录 | `quote-site` 的**上一级** `邮满满云仓报价表/` | 可用 `--data-dir DIR` 覆盖 |
| 支持格式 | `.xls`（Excel 97-2003）、`.xlsx/.xlsm`、`.csv/.txt` | 自动识别，按扩展名选择引擎 |
| 文件命名 | 不限，按**工作表名**分类 | 见下方「分类规则」 |
| 运行环境 | Python 3.8+（解析用）；浏览器任意（查看用） | 首次运行会自动建 venv 装依赖 |
| 编码 | `.csv` 默认按 `utf-8-sig` 读取 | 乱码时检查导出编码 |
| 庞大地址表 | 默认**排除**东南亚分区表 / 澳大利亚分区邮编 / 美国偏远邮编地区 | 加 `--include-zones` 纳入 |

### 分类规则（按工作表名自动归类）
- **线路报价**：名称含 专线/快线/标准/商派/挂号/特惠/标快/普货/特货/带电/美国/欧洲/日本/云途 … 等。
- **云仓服务**：名称含 云仓/耗材/仓储/代发/入库/出库/操作费 … 等。
- **参考规则**：名称含 药事法/税率/申报价值/禁运/注意事项/清单/分区表/偏远/邮编/售后/规则 … 等
  （优先级高于线路，避免误判）。

## 三、快速开始（三种方式）

### 方式 A：仅查看已生成的数据（最简单）
直接双击 `quote-site/index.html`，浏览器打开即可看到当前报价。
（前提是 `data/data.js` 已存在——本仓库已附带一版。）

### 方式 B：一键启动（推荐，含自动刷新按钮）
双击 `quote-site/run.bat`：
1. 自动创建 Python 虚拟环境并用清华镜像安装依赖；
2. 运行 `parse_prices.py` 解析最新报价；
3. 启动本地服务器 `http://localhost:8765` 并打开浏览器。
页面右上角「刷新数据」按钮可一键重新解析（调用 `/refresh` 接口）。

### 方式 C：手动命令行
```bash
cd quote-site
python -m venv venv && venv\Scripts\activate      # 或用自己的 Python
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
python parse_prices.py                            # 解析 → 生成 data/
python server.py                                  # 起服务 → http://localhost:8765
```

## 三-A、运费试算（估算器）

导航栏右侧的琥珀色按钮 **「🧮 运费试算」** 可打开运费估算弹窗，输入参数后即时算出预估运费。

**用法**
1. 点「🧮 运费试算」打开弹窗（桌面端居中模态、移动端底部抽屉）。
2. 选择 **渠道 / 线路**（来自「线路报价」类工作表）与 **目的地 / 产品**。
3. 填入 **重量 (KG)**（必填），选填 **长 / 宽 / 高 (cm)**。
4. 任意输入变化即实时刷新结果，无需点按钮（也可点「计算预估运费」）。

**计算规则**
- 体积重 = 长 × 宽 × 高 ÷ 6000；
- 计费重 = max(实重, 体积重)，并按所选线路「最低计费重」封底；
- 预估运费 = 计费重 × 费率(元/KG) + 挂号费/处理费(每票)。
- 结果随报价表更新而同步（同样走「四、如何更新」的重新解析流程）。

> 说明：估算器直接读取 `data/data.js`，与页面报价同源；因体积重除数、附加费、燃油等未在基础报价表中逐项列出，结果**仅供参考**，实际以客服核价为准。

## 四、如何更新（新增 / 替换报价文件后）

**核心动作：把新报价文件放进数据源目录，重新跑一次解析脚本。**

1. 把新的报价表（`.xls` / `.xlsx` / `.csv`）复制到 `邮满满云仓报价表/` 文件夹，
   或替换掉同名旧文件。**无需改动任何代码**。
2. 重新解析：
   - 若用 `run.bat` 启动的服务器仍在运行 → 直接点页面右上角「刷新数据」；
   - 或在 `quote-site/` 下双击 `refresh.bat`；
   - 或命令行 `python parse_prices.py`。
3. 解析成功后：
   - `data/data.js` 写入**新版本**（版本号 +1）、记录更新时间；
   - 旧版本自动备份到 `data/data.prev.js`；
   - `data/status.js` 标记 `ok:true`，页面顶部显示新的版本号与日期。
4. 若解析**失败**（文件损坏 / 目录为空 / 全部工作表解析异常）：
   - `data/data.js` **原样保留**（回退到上一版可用数据）；
   - `data/status.js` 标记 `ok:false` 并写明原因与 `fallbackVersion`；
   - 页面顶部弹出红色报错横幅「已回退至上一版本」，数据仍可正常查看。
   - 修复文件后重新跑解析即可恢复正常。

> 提示：版本号与更新时间始终显示在页面顶部导航栏右侧（青绿胶囊）。

## 五、解析脚本参数

```bash
python parse_prices.py [--data-dir DIR] [--out-dir DIR] [--include-zones] [--force]
```
- `--data-dir DIR`  指定数据源目录（默认 `../邮满满云仓报价表`）
- `--out-dir DIR`   指定输出目录（默认 `./data`）
- `--include-zones` 一并纳入庞大的邮编 / 分区对照表（默认排除，避免拖慢网页）
- `--force`         即使内容无变化也重写（版本号仍递增）

## 六、排错

| 现象 | 处理 |
|------|------|
| 页面打开是空白 / 只显示标题 | 确认 `data/data.js` 与 `data/status.js` 存在；先跑一次 `python parse_prices.py` |
| 顶部显示红色「已回退至上一版本」 | 数据源文件损坏或为空；检查 `邮满满云仓报价表/` 内的文件，修复后重新解析 |
| 某个工作表没出现 | 可能被分类为「参考规则」或在默认排除列表；加 `--include-zones` 或检查工作表名关键词 |
| 金额列没显示 ¥ / 数字没右对齐 | 表头需含 元/RMB/价格/运费/费 等关键词；纯标签列（如「收费项目」）不会当作金额 |
| `.csv` 乱码 | 确认导出为 UTF-8（带 BOM 最佳）；脚本默认 `utf-8-sig` |
| 端口 8765 被占用 | 设环境变量 `QUOTE_PORT=9000` 后重跑 `server.py` |

## 七、技术说明（给维护者）

- **解析**：`parse_prices.py` 按扩展名选引擎——`.xls` 用 `xlrd==1.2.0`（2.x 已不支持 xls），
  `.xlsx` 用 `openpyxl`，`.csv` 用标准库。自动检测表头行、裁剪合并单元格残留的空白列、
  按工作表名分类、统一金额/单位书写（如「运费 （RMB/KG）」→「运费(RMB/KG)」）。
- **前端**：`assets/app.js` 为原生 JS（无框架），读取全局变量渲染；支持分类标签页、
  工作表胶囊切换、关键词高亮、分类列下拉筛选、表头点击排序、URL 深链（`?cat=&sheet=&q=`）。
- **版本与回退**：每次成功写入前备份上一版；整体失败时只写错误状态、保留旧数据，
  保证网页**永不因解析失败而白屏**。
- **兼容 file://**：数据以 `<script>` 注入，双击 `index.html` 即可离线查看最新已生成的数据。
