# 禁运品清单

| 内容    |
|  -  |
| 禁运品清单  |  主要禁限运品清单    |
| 1.爆炸品：如雷管、导火索、导爆索、电点火头、发射炸药、烟花、鞭炮、摔炮、拉炮等    |
| 2.危险气体类：如打火机、电子点烟器、打火机补充气罐、氢气、甲烷、乙烷、丁烷等    |
| 3.危险液体类：一氧化碳、一氧化氮、氯气、硫化氢、汽油、煤油、油漆、花露水、香水、指甲油、啫喱膏、驱蚊水、杀虫剂、酒精、香蕉水、松节油等    |
| 4.危险固体类:如红磷、硫磺、铝粉、闪光粉、活性炭、镁棒、发射药、硝化棉、金属钠、钾、锂、锌粉、黄磷、白磷、硝化纤维（含胶片）、钛粉等    |
| 5.氧化性物质及有机过氧化物:如高锰酸盐、高氯酸盐、氧化氢、过氧化钠等    |
| 6.毒性物质:如砷、砒霜、汞化物、铊化物、氰化物、硒粉、苯酚、汞、剧毒农药等    |
| 7.放射性物质:如铀、钴、镭、钚等    |
| 8.腐蚀性物质:如硫酸、硝酸、盐酸等    |
| 9.杂项危险品    |
| ①枪支（含仿制品、零部件）    |
| ②弹药（含仿制品）：如子弹、炸弹、手榴弹、火箭弹、照明弹、燃烧弹、烟幕(雾)弹、信号弹、催泪弹、毒气弹、地雷、手雷、炮弹、火药等。    |
| ③管制刀具：匕首（带有刀柄、刀格和血槽，刀尖角度小于60度的单刃、双刃或多刃尖刀）、三棱刮刀（具有三个刀刃的机械加工用刀具）、带有自锁装置的弹簧刀或跳刀（刀身展开或弹出后，可被刀柄内的弹簧或卡锁固定身锁的折叠刀具）、其他类似的单刃、双刃三棱尖刀（刀尖角度小于60度刀身长度超过150毫米的各类单刃、双刃、多刃刀具）以及刀尖角度大于60度刀身长度超过220毫米的各类单刃、双刃、多刃刀具等    |
| ④攻击性武器：如弩、催泪器、催泪枪、电击器、铁莲花、电棍，伸缩棍，指虎、双截棍、弹弓、棒球棍、飞镖、复合弓、弓箭等。    |
| 二、航空限制品    |
| 1.电池类    |
| ①超功率电池产品：总功率大于100Wh，且总电池容量大于10000mA    |
| ②部分功率电池产品：纯电（充电宝、移动电源等）、非配套电池、超量配套电池、含液体的电动喷雾器、未经检测/认证/无标识的配套电池产品    |
| 2.化工产品：如樟脑丸、泡腾片，清洁泡腾剂等    |
| 3.部分强磁类产品：如打捞磁铁，磁力魔方，磁铁等。    |
| 三、清关禁运品    |
| 1.烟草：如卷烟、雪茄、烟丝等    |
| 2.毒品及吸毒工具、非正当用途麻醉药品和精神药品、非正当用途的易制毒化学品    |
| ①毒品、麻醉药品和精神药品：如鸦片(包括罂粟壳、花、苞、叶)、吗啡、海洛因、可卡因、大麻、甲基苯丙胺(冰毒)、氯胺酮、甲卡西酮、苯丙胺、安钠咖等。    |
| ②易制毒化学品：如胡椒醛、黄樟素、黄樟油、麻黄素、伪麻黄素、羟亚胺、邻酮、苯乙酸、溴代苯丙酮、醋酸酐、甲苯、丙酮等。    |
| ③吸毒工具：如冰壶、水烟壶等。    |
| 3.感染性物质：如病菌、炭疽、寄生虫、排泄物等    |
| 4.动植物产品：如活体毒蝎、浸制蛇标本、昆虫标本、新鲜水果蔬菜、种子、花卉、干花、草药、树枝、原木等    |
| 5.国家货币、外币及其有价证券或非法仿造物品：如现金、钞票、仿币、古币、冥币、支票、激活的信用卡、伪造的证件、银行卡等    |
| 6.赌博用具：如赌博筹码、电动赌博设备、老虎机组件等    |
| 7.珍贵文物及其它禁止出境的文物：如古董、古籍、陶瓷、字画、碑帖等    |
| 8.无线电收发信机、通信保密机：如军用电台、监听设备、保密通信设备等    |
| 9.微生物、人体组织、生物制品、血液及其制品等特殊物品：如真人发丝、疫苗、人体组织等    |
| 10.侵犯知识产权和假冒侵权    |
| ①侵犯知识产权：如未经权利人许可直接使用、传播有权利人注册信息的相关产品，侵权包括外观侵权及商标侵权等，（知识产权注册信息查询网址：http://202.127.48.145:8888/zscq/search/jsp/vBrandSearchIndex.jsp；全球：https://branddb.wipo.int/branddb/en/）    |
| ②假冒侵权：与知名品牌近似，致使消费者产生混淆的商品，如“Adibos”、“Nkie”、“Appie”等    |
| 四、清关限制品    |
| 1.药品或无法分辨的疑似药品颗粒产品：如痔疮膏、药贴等    |
| 2.食品：如零食、保健品、功能性饮料、茶包、干果、泡面等    |
| 3.无成分标识的液体、粉末类产品    |
| 4.出版物、印刷品、音像制品等宣传品：如非法的印刷品、胶卷、照片、唱片、影片、录音带、录像带、激光视盘、计算机存储介质、包括非法的地图、中国国旗，党徽，党旗，军旗等等    |
| 5.军警用品：如军靴、迷彩服装、钢盔、手铐、警棍、防弹衣、军警护具等产品    |
| 6.金银等贵重金属及其制品：如金条、金锭等    |
| 7.电子烟及其制品：如电子烟设备、烟弹、烟油等    |
| 8.医疗器械：如针头注射器等    |
| 9.部分枪型玩具及工具：如水弹、泡沫软弹、BB弹、炮钉枪（不含炮钉）、花园灌溉喷枪、枪型穿耳器等等    |
| 10.无人机及其配件类：如具有拍摄功能的飞行玩具、无人机等    |

| ②铝合金和钛合金：如铝合金和钛合金等    |
