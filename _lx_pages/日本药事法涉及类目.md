| 《药事法》主要监管对象及法律定义    |    |    |    |    |    |
| 监管对象    |法律定义    |    |    |    |    |
| 医药品    |1. 收录于日本药典的物品 2. 用于诊断、治疗或预防人类或动物疾病，且不属于器械工具等的物品 3. 用于影响人体或动物体结构或功能，且不属于器械工具等的物品    |    |    |    |    |
| 医药部外品    |1. 具有以下四种用途、对人体影响较小、且不属于器械工具等的物品 1)预防恶心等不适、口臭或体臭 2)预防痱子、疮疡等 3)预防脱发、毛发生长或脱毛 4)防治老鼠、苍蝇、蚊子、跳蚤及其他类似生物，以维护人类或动物健康为目的 2. 厚生劳动省指定物品    |    |    |    |    |
| 化妆品    |以涂抹、喷洒或其他类似方式涂抹于人体，用于清洁、美化、提升人体魅力、改变容貌、保持皮肤或毛发健康等目的，且对人体有轻微作用的物品    |    |    |    |    |
| 医疗器械    |用于诊断、治疗或预防人类或动物疾病，或者影响人体或动物体结构或功能的器械工具等    |    |    |    |    |

| 《药事法》于1960年由日本国会批准通过并颁布，2014年管控范围扩展到医疗器械相关，故又叫做《药械法》； 主要监管对象是医药品、医药部外品、化妆品、医疗器械等； 目的是通过确保这些产品的质量、功效和安全性，保障公共健康。    |    |    |    |    |    |
